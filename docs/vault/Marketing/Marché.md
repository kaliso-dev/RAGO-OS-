# Marché

Retour à [[Projet]]. Détail : `docs/plan/Rago_Etude_Marche.md` (sources Steam Survey 2026).

**Le besoin « jeux Windows sur Linux » est déjà résolu et gratuit** (Proton, SteamOS, Bazzite, CachyOS). **Mais la bascule fluide pour les jeux anti-triche n'est packagée par personne** — le dual-boot manuel (reboot complet, Windows entier) est unanimement vécu comme pénible. **C'est le créneau vide de Rago.**

Taille : Linux ~5,33 % des joueurs Steam (mars 2026, record, ~double en un an) = ~7 M de joueurs Linux. Mais le marché *adressable* par Rago (joueurs anti-triche frustrés du dual-boot, prêts à payer) est une **niche** (dizaines à centaines de milliers).

**Risque (moat temporel)** : les anti-triche s'ouvrent lentement à Linux ([[Vanguard On-Demand]]). Si un jour Valorant/Fortnite tournent nativement, l'accroche s'érode → miser la valeur durable sur l'optimisation, pas seulement la bascule.
