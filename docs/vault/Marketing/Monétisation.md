# Monétisation

Retour à [[Projet]], [[Marché]]. Statut : **À DÉCIDER**.

Contrainte : les concurrents sont **gratuits** (SteamOS, Bazzite, CachyOS) ; la communauté Linux rejette l'abonnement pour un OS.

**Reco (conseil, pas décision)** :
- **Freemium** : base **gratuite/open source** (crédibilité + communauté) + **Rago Pro one-time ~30-40 €** (switch fluide + profils par jeu + support). Éviter l'abonnement pur.
- **[[Rago Console coreboot]]** : la vraie marge (modèle Steam Deck), mais c'est un métier de hardware, plus tard.

**Pour Sofiene (17 ans)** : à cet âge, l'**opportunité** (projet open source impressionnant → admissions, stages, réseau) vaut plus que l'argent direct d'une niche. Publier gratuitement d'abord, monétiser si la traction est là.
