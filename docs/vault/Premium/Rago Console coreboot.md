# Rago Console (firmware coreboot)

Retour à [[Projet]], [[Innovations avancées]], [[Loi physique du POST]]. Statut : **R&D / vision 2-3 ans**.

La seule façon de casser le plancher du POST : remplacer le firmware vendeur par **coreboot** (firmware ouvert) sur du **matériel certifié**. Les machines coreboot bootent en **< 1 s** → le [[Fast OS Switch]] pourrait viser **~3-5 s** au lieu de ~10-13.

Impossible sur une carte vendeur arbitraire (flasher = risqué/impossible) → réservé à une **SKU premium** : une gamme de PC/console Rago préflashés. Modèle Steam Deck (logiciel gratuit + matériel vendu plus cher).

C'est une **stratégie produit** (métier de hardware : fabrication, SAV) à n'activer qu'après le logiciel. Voir [[Monétisation]].
